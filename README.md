# ConsoleChat – консольный чат на C++

## О проекте

Это мой итоговый проект по C++ на курсе SkillFactory.

Я сделала простой консольный чат, в котором можно зарегистрироваться, войти в аккаунт, отправлять личные сообщения другим пользователям и писать в общий чат.

Программа работает через консоль, без графического интерфейса.

## Что умеет программа

- Регистрировать новых пользователей по логину, паролю и имени.
- Проверять, занят ли логин.
- Выполнять вход по логину и паролю.
- Отправлять личные сообщения определённому пользователю.
- Показывать отправленные и полученные личные сообщения.
- Отправлять сообщения в общий чат.
- Показывать сообщения общего чата всем пользователям.
- Выходить из аккаунта.
- Сообщать об ошибке, если выбран неправильный пункт меню.

## Как устроена программа

Для проекта я использовала три класса.

### User

Класс `User` хранит информацию о пользователе: логин, пароль и имя.

Функции:
- `getLogin()` – возвращает логин.
- `getName()` – возвращает имя.
- `checkPassword()` – проверяет введённый пароль.

### Message

Класс `Message` хранит информацию о сообщении: кто его отправил, кому оно предназначено и сам текст.

Функции:
- `getSender()` – возвращает отправителя.
- `getReceiver()` – возвращает получателя.
- `getText()` – возвращает текст сообщения.

Для общего чата я использовала значение `ALL` вместо логина получателя.

### Chat

Класс `Chat` отвечает за основную работу программы. В нём хранятся пользователи и сообщения, а также реализовано меню.

Функции:
- `findUser()` – ищет пользователя по логину.
- `registerUser()` – регистрирует нового пользователя.
- `loginUser()` – проверяет логин и пароль.
- `logoutUser()` – выполняет выход из аккаунта.
- `sendPrivateMessage()` – отправляет личное сообщение.
- `showPrivateMessages()` – показывает личные сообщения пользователя.
- `sendPublicMessage()` – отправляет сообщение всем пользователям.
- `showPublicMessages()` – показывает сообщения общего чата.
- `showMenu()` – выводит меню и обрабатывает выбор пользователя.

В функции `main()` создаётся объект `Chat` и запускается меню.

## Как пользоваться чатом

Сначала нужно зарегистрировать пользователя, указав логин, пароль и имя. После этого можно войти в аккаунт.

В меню авторизованного пользователя доступны личные сообщения и общий чат.

Например, один пользователь может написать сообщение в общий чат, выйти из аккаунта, а другой — войти и прочитать его. Также пользователи могут переписываться лично.

Пока все данные хранятся в памяти программы. После её закрытия пользователи и сообщения не сохраняются.

## Как запустить

1. Открыть проект `Chat_C++.slnx` в Visual Studio.
2. Собрать проект.
3. Нажать `Ctrl + F5`, чтобы запустить программу.

Основной код находится в файле `Chat_C++/Chat_C++.cpp`.
